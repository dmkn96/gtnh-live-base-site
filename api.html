JSON API истории

Доступен всем без ключа. Только данные об изменениях GT-машин, труб и кабелей; координаты совпадают с относительными координатами карты. Обновление — вместе с картой.

В скриптах укажите имя приложения в HTTP-заголовке User-Agent, например GTNH-History-Client/1.0. Браузер заполняет его сам. Стандартный Python-urllib может получить ошибку 403/1010 ещё до API — это проверка клиента на стороне Cloudflare, а не требование авторизации.

Запрос за промежуток игрового времени

GET https://gtnh-base-history-api-dmkn96.equal-bee-5135.chatgpt.site/api/v1/changes?from=00:00:00&to=01:00:00

Открыть пример JSON. Можно указывать секунды: from=3600&to=7200, либо тики: from_tick=72000&to_tick=144000. Один тик = 1/20 секунды. Начало включено, конец исключён: [from, to).

curl -A 'GTNH-History-Client/1.0' \
  'https://gtnh-base-history-api-dmkn96.equal-bee-5135.chatgpt.site/api/v1/changes?from=01:00:00&to=02:00:00&download=1' \
  -o changes.json

Запрос по дате и времени

GET /api/v1/changes?clock=utc&from=2026-10-24T00:00:00Z&to=2026-10-25T00:00:00Z

Обязателен часовой пояс: Z или смещение, например +10:00 (знак «+» в URL кодируется как %2B). Поле precision показывает, известно ли точное время: recorded — запись Audit; observed — изменение обнаружено при публикации снимка. Фильтр UTC использует поле at; для наблюдений это время обнаружения, а не точное время действия игрока.

Несколько промежутков

POST /api/v1/changes
Content-Type: application/json

{
  "clock": "igt",
  "intervals": [
    {"from": "01:00:00", "to": "02:00:00"},
    {"from": "03:00:00", "to": "04:00:00"}
  ],
  "limit": 1000
}

До 20 промежутков; пересечения не дублируют события. Для GET такой же массив можно передать в параметре intervals как JSON с URL-кодированием.

События

ТипЗначение
addedДобавлен блок
changedЗамена блока, поворот или изменение известных соединений
removedБлок удалён; время удаления обычно известно лишь по снимку
possible_moveВозможный перенос: в одной публикации найдена единственная пара добавления и удаления такого типа блока. Это предположение, а не доказательство. Исходные события сохранены, их ID находятся в related_event_ids
initialБлок из начального снимка; время его установки неизвестно. Не входит в ответ по умолчанию

Каждая запись содержит стабильный id, tick, время at, первое наблюдение observed_at, состояния before / after и список changed_fields. В precision у возможного переноса указано inferred, у начального снимка — initial. Несколько состояний одного блока, существовавших ноль тиков, не создают лишние события.

Фильтры и скачивание

  • type=added,removed — типы событий; type=moved — псевдоним possible_move.
  • dimension=0 — измерение.
  • limit=200 — размер страницы, максимум 1000. Следующая страница: тот же запрос и cursor из поля next_cursor. Параметры и размер страницы сохраняйте прежними.
  • download=1 — скачать JSON страницы файлом. Для всего результата пройдите страницы либо скачайте полный опубликованный журнал.

total — число совпавших записей, returned — число записей на странице, counts — количества по типам во всём результате. Кандидаты переносов считаются отдельно и не заменяют добавления/удаления. Поддерживается CORS для любых сайтов; серверных логов, игроков, UUID и содержимого инвентарей в ответе нет.

Ошибки: 400 — неверные параметры; 409 — журнал обновился между страницами, начните запрос заново; 413 — слишком большой запрос; 415 — POST без JSON; 502 — источник временно недоступен. При выдаче последней кешированной копии заголовок X-Data-Stale: true предупреждает о недоступном источнике.
